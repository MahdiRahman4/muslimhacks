

# MuslimHacks Website — Implementation Plan

## Overview
A single-page immersive storytelling experience for Quebec's largest Muslim charity hackathon. This is not a landing page—it's an emotional journey through five distinct beats that guide visitors from curiosity to commitment.

## Core Design Principles
- **Asymmetry as intention**: Text alignment, section widths, and element placement will deliberately break conventional patterns
- **Sunset palette**: Warm ambers, deep plums, dusty rose, and twilight blues
- **Emotional whitespace**: Generous, varied spacing that creates rhythm and breath
- **Parallax depth**: Subtle layers of movement—Islamic geometric patterns, particles like snow or stars
- **Typography as voice**: Varying scales, weights, and alignments to create intimacy and impact

## The Five Emotional Sections

### 1. The Opening — Curiosity
- Full-viewport gradient canvas (amber → plum)
- Hadith reveal animation: Arabic calligraphy fades in, followed by English translation
- Source attribution: Jami` at-Tirmidhi 614
- No navigation visible initially—pure immersion
- Subtle floating particles in background

### 2. The Question — Discomfort
- Left-aligned, narrow text column (journal-like intimacy)
- Provocative questions about responsibility and purpose
- Single powerful statistic that bleeds off-screen
- Background shift with drifting particle animation
- Raw, slightly imperfect typography feel

### 3. The Story — Intimacy
- Narrow letter-format layout
- Origin story of MuslimHacks as a niyyah between friends
- Quebec Muslim identity woven in (French/English duality, winter imagery)
- Overlapping photo elements (will use placeholder styling for now)
- Slower scroll rhythm, more whitespace

### 4. The Vision — Expansion
- Full-width explosion of content
- Parallax Islamic geometric patterns in background
- Key information scattered intentionally: 36-hour hackathon, Islamic Relief Canada partnership, September 2026
- Varied text sizes and image placements
- Elements that overlap and bleed beyond containers

### 5. The Invitation — Quiet Resolve
- Colors deepen to twilight
- First centered text: "Will you build with us?"
- Registration/interest form (email capture for now)
- Closing Arabic blessing
- Fade to near-darkness

## Technical Components
- Custom scroll-triggered animations using CSS and intersection observers
- Parallax background layers
- Responsive design that maintains emotional impact on mobile
- Smooth scrolling with varied section heights
- Gradient transitions between sections
- Floating/drifting particle effects
- Islamic geometric pattern SVG backgrounds

## Content Elements
- Featured Hadith with Arabic calligraphy styling
- MuslimHacks origin narrative
- Partnership with Islamic Relief Canada
- Event details (September 2026, Quebec)
- Email signup for registration interest

## Visual Assets Needed
- Islamic geometric patterns (SVG, subtle opacity)
- Particle/snow effect system
- Gradient color palette throughout
- Typography hierarchy (display, body, intimate)

This creates a website that sponsors will recognize as serious and professional, while potential participants will feel drawn into something meaningful—a gathering, not a product launch.
